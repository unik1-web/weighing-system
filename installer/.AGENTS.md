# Каталог: installer/

## Назначение
Сборка Windows-артефактов: standalone `.exe`, setup-пакет и связанные инструкции smoke-проверок.

## Файлы

### build.ps1
- Основной сценарий Windows сборки:
  - `npm run build`,
  - установка python-зависимостей,
  - упаковка через PyInstaller,
  - подготовка smoke-checklist,
  - опциональная сборка setup через Inno Setup.
- Выполняет pre-check:
  - наличие `pyserial` в `server/requirements.txt`,
  - наличие обязательных hidden import для scale runtime в `installer/weighing-system.spec`.

### weighing-system.spec
- PyInstaller spec:
  - entrypoint `server/launcher.py`,
  - включение frontend `dist/`,
  - hidden imports backend runtime-модулей и `serial_backend`.

### weighing-system.iss
- Inno Setup сценарий сборки `WeighingSystem-Setup.exe`.

## Зависимости
- `server/requirements.txt`
- `server/launcher.py`
- `dist/`
