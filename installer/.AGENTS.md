# Каталог: installer/

## Назначение
Сборка Windows-артефактов: standalone `.exe`, setup-пакет и связанные инструкции smoke-проверок.

Две поставки (stage 7 / UC-07):
- **basic** — без OpenCV; `WeighingSystem-Setup.exe`; capability `build=basic`
- **full** — с `opencv-python-headless` и модулем камер; `WeighingSystem-Full-Setup.exe`; capability `build=full`

Данные рядом с exe (не в `_MEIPASS`): `config.ini`, `BD/`, `backup/`, `logs/`, `Photo/`.

## Файлы

### build.ps1
- Основной сценарий Windows сборки:
  - `npm run build`,
  - установка python-зависимостей (basic: `requirements.txt`; full: `requirements-full.txt`),
  - упаковка через PyInstaller,
  - post-build import-smoke (`basic-import` / `full-import`; full без cv2 → fail),
  - подготовка smoke-checklist (stage 6 yearly archive + scale adapters + photo),
  - опциональная сборка setup через Inno Setup.
- Параметры: `-SkipFrontend`, `-SkipInstaller`, `-Full` (полная поставка).
- Выполняет pre-check:
  - наличие `pyserial` в `server/requirements.txt`,
  - basic: отсутствие opencv в requirements; exclude `cv2` в spec,
  - full: `opencv-python-headless` в `requirements-full.txt` + probe import cv2,
  - наличие обязательных hidden import (scale + cameras/photo_storage/ticket_photos) в spec,
  - наличие layout-каталогов `BD/`, `backup/`, `logs/`, `Photo/` в iss (данные рядом с exe, не в `_MEIPASS`),
  - отличимые `OutputBaseFilename` basic vs full.

### weighing-system.spec
- PyInstaller spec **basic**:
  - entrypoint `server/launcher.py`,
  - включение frontend `dist/`,
  - hidden imports backend runtime-модулей, `serial_backend`, import-safe camera modules,
  - `excludes=['cv2', 'opencv']` (документированный exclude EC-06).

### weighing-system-full.spec
- PyInstaller spec **full**:
  - те же entrypoint/datas,
  - hidden imports camera modules + `cv2` / collect_all OpenCV hooks,
  - без exclude OpenCV.

### weighing-system.iss
- Inno Setup сценарий basic → `WeighingSystem-Setup.exe`.
- Создаёт каталоги `{app}\BD`, `{app}\backup`, `{app}\logs`, `{app}\Photo` с правами записи пользователя.

### weighing-system-full.iss
- Inno Setup сценарий full → `WeighingSystem-Full-Setup.exe`.
- Те же layout-каталоги, включая `{app}\Photo`.

### pyi_rth_pypxlib.py
- Runtime hook PyInstaller для pypxlib.

## Зависимости

- `server/launcher.py`
