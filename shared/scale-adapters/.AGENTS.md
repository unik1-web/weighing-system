# Каталог: shared/scale-adapters/

## Назначение
Единый data-only manifest адаптеров весов для frontend и backend. Каталог задаёт канонические `adapter_id`, поддерживаемые transport и версию схемы каталога.

## Файлы

### catalog.json
- `adapter_schema_version` — версия контракта каталога адаптеров
- `transports` — профили transport (`web_serial`, `serial_backend`, `tcp_client`)
- `adapters` — список адаптеров:
  - `microsim-m0601`
  - `newton`
  - `cas`
  - `midl-mi-vda`
  - `generic-regex`

## Зависимости
- Используется в `src/lib/scale-adapters/contract.ts`
- Используется в `server/scale_registry_contract.py`
