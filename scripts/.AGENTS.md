# Каталог: scripts/

## Назначение
CLI smoke-скрипты для production-like проверки backend entrypoint без in-process тест-клиента.

## Файлы

### smoke_scale_api.py
- Runtime smoke `/api/scales/*`:
  - последовательность `connect -> status -> read -> disconnect`;
  - redacted JSON/Markdown отчёты;
  - проверка scale runtime контракта.

### smoke_yearly_archive.py
- Stage-6 production-like smoke с режимами `--scenario`:
  - `active` — `active_year`, session, rotation preview против live `npm start`;
  - `archive` — archive years/tickets/ticket, forbidden-field и sent-REO ветки;
  - `fail-retry` — TF-04 fail after backup + retry на изолированном HTTP server;
  - `parallel-lock` — TF-05 `409 rotation_in_progress` на изолированном HTTP server;
- генерация JSON/Markdown evidence (`status: PASS/FAIL`);
- helpers: `build_report()`, `_render_markdown()`, `IsolatedStage6Server`.
- Wrapper-команды в `package.json`: `smoke:stage6`, `smoke:stage6-archive`, `smoke:stage6-fail-retry`, `smoke:stage6-parallel-lock` (используются CI workflow `yearly-db-archive.yml`).

### run_05_resume.sh
- Служебный скрипт пайплайна resume для stage 5/оркестратора.
