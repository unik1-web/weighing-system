# Каталог: server/scale_transports/

## Назначение
Transport-драйверы backend runtime API весов (`/api/scales/*`).

## Файлы

### serial_backend.py
- `SerialBackendTransport` — чтение COM/TTY через `pyserial`
  - `open(connection)` — открывает порт по persisted serial-конфигурации
  - `read_line(timeout_ms)` — читает одно строковое показание с timeout
  - `close()` — закрывает открытый handle
- `SerialBackendError` — transport-ошибка с каноническими `code/message/http_status`

### __init__.py
- Переэкспорт `SerialBackendTransport` и `SerialBackendError`.

## Зависимости
- `pyserial`
- `server/scale_runtime.py`
