# Каталог: server/

## Назначение
Backend Flask API, persistence-слой и контрактные модули runtime-адаптеров весов.

## Файлы

### app.py
- Flask entrypoint приложения и API:
  - `/api/config`
  - `/api/database`
  - `/api/storage`
  - `/api/scales/*`
  - интеграционные endpoint-ы импорта и РЭО

### scale_api.py
- Runtime API весов:
  - `POST /api/scales/connect`
  - `GET /api/scales/status`
  - `POST /api/scales/read`
  - `POST /api/scales/disconnect`
  - `set_scale_transport_factory(factory)` (test helper)
  - `register_scale_api(error_response)`
  - `invalidate_for_scale_switch(site_id, from_scale_id)`
  - `invalidate_for_database_payload(changed_storage_keys)`

### scale_api_guard.py
- Backend security guard для `/api/scales/*`:
  - `ScaleApiGuard.validate_origin(request)` — allowlist origin/referer
  - `ScaleApiGuard.load_operator_context()` — persisted `app_current_user`
  - `ScaleApiGuard.require_permission(operation, operator_context)`
  - `OperatorContext` — контекст оператора

### scale_runtime.py
- Runtime-оркестрация backend session:
  - `connect()/status()/read()/disconnect()` с проверкой активного комплекта из `app_site_runtime`;
  - preflight integrity-audit перед `connect/read` для active runtime-контура;
  - `invalidate_for_runtime_change()` — закрытие старой сессии и stale-marker;
  - `invalidate_for_database_update()` — инвалидация сессий после критичных изменений `/api/database`.
  - `scale_state_lock` — process-local lock для snapshot/runtime операций.
  - redacted lifecycle logging: `open`, `read`, `disconnect`, `stale`, `error`.

### scale_integrity.py
- Integrity-audit persisted runtime-контура:
  - `run_scale_integrity_audit(connection)` — проверка `sites/scales/site_runtime/app_current_user`;
  - `AuditFinding` и `AuditReport` с разбиением findings на `fatal`/`warning`;
  - fatal findings блокируют только aut-read path.

### scale_transports/serial_backend.py
- Transport-драйвер backend serial I/O:
  - `SerialBackendTransport.open(connection)`
  - `SerialBackendTransport.read_line(timeout_ms)`
  - `SerialBackendTransport.close()`
  - `SerialBackendError` — канонические transport-ошибки.

### sqlite_store.py
- Работа с SQLite и схемой хранения:
  - `init_schema(connection)`
  - `migrate_schema_stage_5(connection)` — add-only migration (`manual_weight_reason`, `PRAGMA user_version = 5`, post-check)
  - `read_database()`
  - `read_runtime_snapshot()` — атомарный runtime snapshot (`sites/scales/site_runtime/app_current_user`)
  - `write_database(data)`

### scale_registry_contract.py
- Контракт загрузки общего manifest и portable regex-валидация:
  - `load_catalog_contract()`
  - `compile_stub_contract()`
  - `validate_portable_regex(connection, test_frame)`
  - `run_builtin_parity_check(fixtures_path)`

### scale_registry.py
- Реестр backend-адаптеров:
  - `load_adapter_catalog()`
  - `list_adapters()`
  - `get_adapter_schema(adapter_id, transport)`
  - `validate_draft(adapter_id, draft)`
  - `validate_connection(adapter_id, connection)` (включая `generic-regex` parser-status метаданные)
  - `parse_reading(adapter_id, raw, connection)` (включая runtime проверки `generic-regex`)
  - `load_registry_contract_status()`

### tests/test_scale_registry_contract.py
- Контрактные тесты backend/parity по manifest и parser-пайплайну:
  - список `adapter_id` и `adapter_schema_version`
  - schema для `generic-regex`
  - E2E-последовательность `list -> schema -> validate -> parse`
  - parity-check по `tests/fixtures/scale-adapters/builtin-readings.json`

### tests/test_scale_api_stub_smoke.py
- Smoke тест stub runtime API:
  - `connect -> status -> read -> disconnect`

### tests/test_scale_api_contract.py
- Контрактные тесты `/api/scales/*`:
  - success/error payload и HTTP codes для `connect/status/read/disconnect`;
  - `inactive_scale_mismatch`, `stale_session`, `invalid_connection_config`, `unsupported_transport`, `transport_unavailable`, `read_timeout`.

### tests/test_scale_api_security.py
- Security-тесты `/api/scales/*`:
  - forbidden `Origin`, отсутствующая active session, недостаточные права;
  - подтверждение отсутствия wildcard CORS.

### tests/test_scale_runtime_switch.py
- Интеграционные тесты stale lifecycle:
  - switch `primary -> spare` инвалидирует старый `session_id`;
  - `status/read/disconnect` на stale session возвращают `409 stale_session`;
  - unrelated `/api/database` update не рвёт активную сессию;
  - `connect` идемпотентно переиспользует живую session.

### tests/test_scale_runtime_registry.py
- Lifecycle tests backend runtime registry:
  - idempotent `connect`/`disconnect`;
  - stale после switch и config write;
  - purge истёкших stale-marker;
  - `session_registry_overloaded`.

### tests/test_scale_registry_generic_regex.py
- Unit/E2E тесты backend для `generic-regex`:
  - portable compile/preview validation
  - parity кодов ошибок лимитов
  - runtime mismatch и `runtime_frame_too_large`

### tests/test_scale_adapter_parity.py
- Backend parity tests shared fixture-pack:
  - built-in adapters;
  - `generic-regex` fixtures.

### tests/test_scale_api_guard.py
- Unit-тесты security guard:
  - запрет неразрешённого `Origin`
  - отказ без active operator-session

### tests/test_scale_integrity.py
- Unit-тесты integrity-аудита и backend redaction:
  - `fatal`/`warning` findings;
  - redaction приватных `COM/TTY/IP` в structured runtime logging.

### tests/test_serial_backend_transport.py
- Unit-тесты `serial_backend`:
  - mapping timeout -> `read_timeout`
  - mapping open/read ошибок -> `transport_unavailable`

### tests/test_stage5_migration.py
- Тесты migration runbook stage 5:
  - backup/import round-trip с `manual_weight_reason_policy`, `manual_weight_reason`, расширенным `connection`;
  - идемпотентность `migrate_legacy_storage()` и проверка создания backup-пары.
