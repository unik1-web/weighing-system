# Каталог: src/lib/scale-adapters/

## Назначение
Каталог содержит frontend-контракт адаптеров весов: типы каталога, реестр адаптеров и парсеры для built-in и generic-regex профилей.

## Файлы

### contract.ts
- Типы каталога и draft-конфигурации:
  - `ScaleTransport`
  - `ScaleConnectionDraft`
  - `NormalizedScaleReading`
  - `GenericRegexValidationResult`
  - канонические `validation_error_code` (`regex_pattern_too_long`, `regex_test_frame_too_large`, `regex_non_portable`, `regex_group_index_out_of_range`, `runtime_frame_too_large`)
- Экспорт общего manifest:
  - `SCALE_ADAPTER_CATALOG`

### registry.ts
- API frontend-реестра:
  - `listScaleAdapters()` — список адаптеров и версия схемы
  - `getAdapterSchema(adapterId, transport)` — schema полей transport/parser
  - `validateScaleConnectionDraft(adapterId, draft)` — проверка совместимости `adapter_id`, `device_id`, `transport`
  - `previewScaleConnectionDraft(adapterId, draft, testFrame)` — preview portable validation для `generic-regex`
  - `parseReading(adapterId, raw, connection)` — парсинг кадра через parser выбранного адаптера
  - `parseScaleReadingStub(adapterId, draft, raw)` — совместимый alias поверх `parseReading()`

### generic-regex.ts
- Реализация portable regex-адаптера:
  - `validateGenericRegexDraft(connection, testFrame)` — compile/preview validation для JS/Python-подмножества
  - `applyGenericRegexValidationResult(connection, result)` — перенос статуса validation в `connection.parser`
  - `parseGenericRegexReading(raw, connection)` — runtime parsing с защитой лимита frame `<=1024`

### builtin/microsim-m0601.ts
- Built-in parser:
  - `parseMicrosimFrame(raw, connection)`

### builtin/newton.ts
- Built-in parser:
  - `parseNewtonFrame(raw, connection)`

### builtin/cas.ts
- Built-in parser:
  - `parseCasFrame(raw, connection)` — учитывает `line_terminator`

### builtin/midl-mi-vda.ts
- Built-in parser:
  - `parseMidlMiVdaFrame(raw, connection)`

## Зависимости
- `shared/scale-adapters/catalog.json` — единый source of truth по `adapter_id`
- `src/lib/scales.ts` — текущая интеграция Web Serial runtime
