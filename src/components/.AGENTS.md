# Каталог: src/components/

## Назначение
Компоненты пользовательского интерфейса: форма взвешивания, панель автосъёма и экраны настроек.

## Файлы

### WeighingForm.tsx
- Компонент `WeighingForm`:
  - фиксирует вес через `ScalePanel` и ручной ввод;
  - по `SITE_RUNTIME_CHANGED_EVENT` пересчитывает активный scale context;
  - новые create/update операций талонов пишут `site_id`, `scale_id`, `scale_role`, `scale_device` из текущего активного комплекта;
  - поддерживает поле `manual_weight_reason`;
  - применяет валидацию обязательности причины только к весам текущего шага;
  - при dual completion не очищает существующую причину без явного действия оператора;
  - пишет runtime-логи блокировки нестабильной фиксации, отказа `manual_weight_reason` и сохранения источников `manual/instrument`.

### ScalePanel.tsx
- Компонент `ScalePanel`:
  - подключает runtime для активного комплекта;
  - показывает источник чтения (`Browser Web Serial` / `Backend API`) и runtime-статус;
  - отображает предупреждения для нестабильного веса по матрице `stable_mode`;
  - обрабатывает режим `manual_only` и явный action `Повторить подключение`;
  - сообщает родителю о блокировке захвата нестабильного веса через `onUnstableBlocked`.

### SiteScalesSettingsSection.tsx
- Компонент `SiteScalesSettingsSection`:
  - редактирует draft-конфигурации `primary` и `spare`;
  - сохраняет `adapter_id` и `connection_json`;
  - блокирует сохранение при compile/preview ошибках `generic-regex`;
  - показывает статус `pending_runtime` для конфигураций без `test_frame`;
  - отображает active set, `adapter_id`, `transport` и статус подключения после switch;
  - пишет runtime-логи успешного сохранения конфигурации, невалидного draft и переключения `primary/spare`.

### ScaleSetSwitchWizard.tsx
- Компонент `ScaleSetSwitchWizard`:
  - выполняет switch через `applyScaleSetSwitch()`;
  - показывает явное сообщение при no-op (уже активный комплект);
  - предупреждает о переходе в `manual_only` для комплекта без рабочей конфигурации.

### ScaleConnectionFields.tsx
- Компонент `ScaleConnectionFields`:
  - рендерит transport/parser-поля в зависимости от `adapter_id` и `transport`;
  - для `generic-regex` поддерживает `pattern`, `flags`, `weight_group`, `stability_group`, `stable_values`, `unstable_values`, `unit_group`, `test_frame`;
  - отображает результат preview-валидации до сохранения.

### SettingsView.tsx
- Компонент `SettingsView`:
  - содержит глобальные настройки приложения;
  - включает `manual_weight_reason_policy`;
  - отображает ошибки draft-конфигураций секции комплектов.

## Зависимости
- `src/lib/site.ts` — доменные операции площадки и комплектов.
- `src/hooks/useScale.ts` — runtime-хук автосъёма.
- `src/lib/storage.ts` — сохранение настроек и талонов.
