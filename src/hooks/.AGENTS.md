# Каталог: src/hooks/

## Назначение
Переиспользуемые React-хуки для UI-слоя.

## Файлы

### useScale.ts
- Хук `useScale`:
  - работает через `ScaleRuntimeClient`;
  - публикует `reading`, `connected`, `error`, `manualOnly`, `transport`, `status`;
  - переводит UI в `manualOnly` при runtime fallback;
  - даёт действия `connect(activeScale)` и `disconnect()`.

### useYearRotation.ts
- Хук `useYearRotation`:
  - orchestrates `POST /api/year/rotation/preview` и `POST /api/year/rotation/commit`;
  - хранит `preview`, `blockingTickets`, `pendingReoCount`, `submitting`, `completed`, `error`;
  - учитывает backend-флаг `rotation_required` и коды stage-6 ошибок;
  - использует extension points `beginRotationCommitSyncPause/endRotationCommitSyncPause` во время commit.
  - поддерживает callback post-commit для принудительного logout flow.

## Зависимости
- `src/lib/scale-runtime-client.ts` — runtime-клиент stub-потока.
 - `src/lib/scale-runtime-client.ts` — runtime-клиент реального Web Serial / backend API потока.
- `src/lib/storage.ts` — тип `Scale`.
- `src/lib/api.ts` — stage-6 API контракты.
