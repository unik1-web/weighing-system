# Система учёта автомобильных взвешиваний

Веб-приложение для полигона отходов: регистрация взвешиваний, журнал, печать актов и талонов, отправка данных в РЭО и импорт из базы Vescom (Firebird).

## Возможности

- **Взвешивание** — ввод брутто/тары, расчёт нетто и суммы, работа со справочниками
- **Журнал** — поиск, фильтры, экспорт CSV, печать, массовая отправка в РЭО
- **Отчёты** — сводка по периодам
- **Справочники** — авто, водители, грузы, контрагенты, пользователи (для администратора)
- **Печать** — акт взвешивания или талон (настраивается в параметрах)
- **Интеграция с РЭО** — отправка завершённых записей по выбранным видам груза
- **Импорт из Vescom** — загрузка взвешиваний из Firebird-базы Vescom (опционально)

Данные журнала и справочников сохраняются в **SQLite** (`BD/weighing.db`), настройки — в **`config.json`** в каталоге приложения. Для РЭО и Vescom используется локальный Python API.

> **Важно:** у каждого адреса браузера свой `localStorage` (`localhost:5173` ≠ `127.0.0.1:5001`). Для постоянной работы используйте `npm start` после `npm run build` — файлы `config.json` и `BD/` общие для всех запусков.

## Установка

```bash
git clone https://github.com/unik1-web/weighing-system.git
cd weighing-system

# Frontend
npm install

# Backend (REO + Vescom)
pip install -r server/requirements.txt
```

## Запуск

Нужны **два процесса** — frontend и backend.

**Терминал 1 — API-сервер:**

```bash
npm run dev:api
```

Сервер запустится на `http://127.0.0.1:5001`. Логи пишутся в `server/logs/app.log`.

**Терминал 2 — веб-интерфейс:**

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`. Запросы к `/api` проксируются на backend.

### Продакшен (один процесс)

Соберите frontend и запустите Flask — он раздаёт интерфейс и API с одного порта:

```bash
npm run build
npm start
```

Откроется `http://127.0.0.1:5001`. Браузер запускается автоматически (`OPEN_BROWSER=0` — отключить).

## Первый вход

При первом запуске создаётся учётная запись администратора:

| Логин | Пароль |
|-------|--------|
| `admin` | `admin123` |

Рекомендуется сменить пароль через **Справочники → Пользователи**.

## Настройка перед работой

Откройте вкладку **Настройки** и сохраните параметры.

### Реквизиты организации
Используются в печатных формах (акт, талон).

### Макет печати
- **Акт взвешивания** — классический акт, 2 экземпляра на листе
- **Талон (квитанция)** — 3 экземпляра на листе

### Интеграция с РЭО
1. Включить интеграцию
2. Указать URL сервиса, ID объекта, ключ доступа
3. Выбрать **виды груза** для отправки
4. Нажать **Проверка РЭО** (backend должен быть запущен)
5. **Сохранить настройки**

Отправка выполняется из **Журнала** кнопкой **«Отправить в РЭО»** — уходят все подходящие неотправленные завершённые записи.

### База Vescom (Firebird)
1. Включить **«Импорт из Vescom»**
2. Указать путь к `.fdb`, например:
   ```
   C:\Program Files (x86)\Vescom\StaticTruckScale\Database\STATICTRUCKSCALE.fdb
   ```
3. Пользователь по умолчанию: `SYSDBA` / `masterkey`
4. **Проверка Vescom** → **Сохранить настройки**
5. Появится вкладка **Импорт Vescom**

## Логирование

### Frontend (браузер)

Модуль `src/lib/logger.ts` записывает события уровней `info`, `warn`, `error` (в режиме разработки также `debug`):

- вход/выход пользователей
- сохранение взвешиваний
- отправка в РЭО
- импорт Vescom
- API-запросы и ошибки

Логи сохраняются в `localStorage` (ключ `app_logs`, до 500 записей) и дублируются в консоль браузера (F12 → Console).

Просмотр в консоли:

```javascript
JSON.parse(localStorage.getItem('app_logs'))
```

### Backend (Python)

- Консоль — все запросы и операции
- Файл — `server/logs/app.log` (ротация до 5 файлов по 2 МБ)

Примеры записей: HTTP-запросы, проверка/отправка РЭО, чтение Vescom, ошибки подключения.

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| «Backend не отвечает» | Запустите `npm run dev:api` |
| Ошибка `fdb` / Vescom | Используйте Python 3.11/3.12, установите Firebird client |
| Кнопка «Отправить в РЭО» неактивна | Проверьте настройки РЭО, виды груза, завершённые записи |
| Вкладка Vescom не видна | Включите переключатель в настройках и сохраните |
