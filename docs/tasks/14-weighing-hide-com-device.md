# 14. Убрать выбор COM и модели прибора с экрана взвешивания

## Проблема

На панели «Весовой прибор» в режиме взвешивания (`ScalePanel`) оператор видит и меняет **модель прибора** и **COM-порт**. Это дублирует настройки площадки/весов и провоцирует ошибочную смену порта во время работы.

## Цель

1. В режиме взвешивания убрать UI выбора модели прибора и COM-порта.
2. Выбор транспорта, модели (`adapter_id`) и COM — **только** в Настройки → площадка/весы.
3. На форме взвешивания оставить: статус подключения, индикатор веса, Подключить/Отключить, Зафиксировать вес; подсказки I/O при отсутствии данных — по возможности.
4. Подключение использует параметры активного комплекта из настроек (`getActiveScaleContext`), без локального перевыбора порта на форме.

## Зависимости

Этап 5 (scale-adapters), serial COM (если есть).
