# 13. Повторный съём эталонов камеры без удаления

## Проблема

В настройках камеры кнопки «Эталон primary» / «Эталон spare» есть, но повторно снять/обновить эталон на практике нельзя — приходится удалять камеру и создавать заново. Превью текущего снимка и уже сохранённые эталоны отображаются, действия пересъёма не работают надёжно (ошибка API, устаревший `camera_id` в БД, отсутствие перезаписи файла и т.п.).

## Цель

1. Повторное нажатие «Эталон primary» / «Эталон spare» всегда переснимает кадр с текущим URL камеры и **перезаписывает** эталон (primary/spare) без удаления камеры из реестра.
2. После успеха превью эталона в UI обновляется сразу.
3. Понятная ошибка оператору при сбое снимка (URL, OpenCV, сеть) — без «тихого» отказа.
4. Не ломать wizard переключения primary/spare и сверку с эталоном.

## Зависимости

Этапы 7 (photo-capture), 10 (настройки камер).
