# 12. Фото при двойном взвешивании: оба заезда + увеличение

## Проблема

При режиме **двойного** взвешивания (тара + брутто) на диск сохраняются снимки обоих заездов (`*_tare_*` и `*_gross_*` в `Photo/…`, плюс пути в истории/аудите). В карточке провески в блоке «Фотофиксация» показываются только превью **одного** заезда (три слота entry/exit/overview). Увеличить снимок нельзя — только мелкие thumbnails.

## Цель

1. В просмотре провески (журнал / карточка) показывать фото **обоих** этапов двойного взвешивания (тара и брутто), сгруппированные по фазе.
2. Дать возможность **увеличить** снимок (lightbox / полноэкранный просмотр) для рассмотрения деталей.
3. Не ломать одиночное взвешивание и случай без фото / `video_enabled=false`.

## Ожидаемое поведение

- Двойное: две группы («Тара» / «Брутто» или по времени фиксации), в каждой — доступные роли камер.
- Клик по превью → увеличенный просмотр (закрытие Esc / клик вне / кнопка).
- Источник данных: `ticket_photos` и/или `photo_*_path` на тикете — не терять уже сохранённые файлы.

## Зависимости

Этапы 7 (photo-capture), 10 (photo-proveska-settings).
