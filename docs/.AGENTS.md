# Каталог: docs/

## Назначение
Техническая и эксплуатационная документация проекта: API, архитектура, задачи и инструкции развёртывания.

## Файлы

### api.md
- HTTP-контракты backend (`/api/config`, `/api/database`, `/api/storage`, `/api/scales/*`).

### architecture.md
- Архитектура frontend/backend, модели данных и потоки синхронизации.

### project-for-agents.md
- Краткий контекст проекта для агентного пайплайна.

### scale-adapters-deploy.md
- Runbook stage 5:
  - предусловия,
  - backup/rollback пары `config.ini` + `BD/weighing.db`,
  - migration `schema_version = 5`,
  - smoke для `serial_backend` и Windows `.exe`,
  - действия при `manual_only`, `stale_session`, `unsupported_transport`.

## Зависимости
- `README.md` — пользовательские инструкции запуска.
- `server/` — реализация API и миграций, на которые ссылаются runbook и контрактная документация.
