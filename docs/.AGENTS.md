# Каталог: docs/

## Назначение
Техническая и эксплуатационная документация проекта: API, архитектура, задачи и инструкции развёртывания.

## Файлы

### api.md
- HTTP-контракты backend (`/api/config`, `/api/database`, `/api/storage`, `/api/scales/*`, stage-6 archive/rotation).

### architecture.md
- Архитектура frontend/backend, модели данных и потоки синхронизации.

### project-for-agents.md
- Краткий контекст проекта для агентного пайплайна.

### yearly-db-archive-deploy.md
- Runbook stage 6 (годовые БД и архив):
  - подготовка окружения (`BD/`, `backup/`, `logs/`, `active_year`, lock),
  - запрет хранения данных в `_MEIPASS`,
  - preflight backup и первичная миграция legacy,
  - `migration_target_exists`, mixed legacy, rollback,
  - годовая ротация (auto-start, lock, stale recovery, повторный вход),
  - smoke active/archive/rotation/print и scale regression,
  - ссылки на CI workflow `yearly-db-archive.yml` и `release-checklist.md`.

### scale-adapters-deploy.md
- Runbook stage 5:
  - предусловия,
  - backup/rollback пары `config.ini` + `BD/weighing.db`,
  - migration `schema_version = 5`,
  - smoke для `serial_backend` и Windows `.exe`,
  - действия при `manual_only`, `stale_session`, `unsupported_transport`.

## Зависимости
- `README.md` — пользовательские инструкции запуска.
- `server/` — реализация API и миграций, на которые ссылаются runbook и контрактная документация.
- `scripts/smoke_yearly_archive.py`, `scripts/smoke_scale_api.py` — production-like smoke из runbook.
