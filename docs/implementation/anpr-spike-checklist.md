# Чеклист спайка ANPR (объект)

Цель: измерить точность локального распознавания на реальных кадрах overview-камеры площадки. Релиз `anpr_enabled=true` в прод — только при **точности ≥ 50%**. Иначе оставить `anpr_enabled=false` (ручной ввод без деградации).

## Подготовка

- [ ] Полная сборка с моделью в `{app_root}/models/anpr/`
- [ ] `video_enabled=true`, камера `role=overview`, ROI настроен на зону номера
- [ ] Active set = **primary**, `anpr_mode=enabled`
- [ ] Зафиксировать версию модели / файл(ы) onnx и дату спайка

## Набор кадров (минимум)

Снять и распознать (кнопка «Распознать номер») не менее **20** проездов / кадров, с разбивкой:

| Условие | Мин. кадров | Ок (номер верный*) | Ошибки |
|---------|-------------|---------------------|--------|
| День, ясно | 5 | | |
| День, пасмурно / низкий контраст | 3 | | |
| Ночь / искусственный свет | 5 | | |
| Дождь / мокрый номер | 3 | | |
| Грязный / частично закрытый номер | 4 | | |
| **Итого** | ≥20 | | |

\*Верный = после нормализации `formatVehiclePlate` совпадает с фактическим номером ТС (до правки оператором). Confidence фиксировать, но в порог 50% входит только match номера.

## Метрика

```
accuracy = ok_count / total_attempts
```

- [ ] accuracy ≥ 0.50 → можно включить `anpr_enabled` по умолчанию на объекте
- [ ] accuracy < 0.50 → оставить выкл.; скорректировать ROI/камеру/модель и повторить спайк

## Негативные проверки (не входят в %)

- [ ] Spare: кнопка недоступна / движок не вызывается; `anpr_status=disabled_by_configuration`
- [ ] Обрыв камеры / нет модели → `failed`, взвешивание продолжается вручную
- [ ] Принять / править / вручную → корректные `plate_source` и автоподстановка
